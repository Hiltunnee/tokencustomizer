# TokenCustomizerTool

[Token customizer tool](https://tokencustomizer.onrender.com/) to help customers plan their order.
Sends the customization plan to Priimacraft via email and guides the customer to place the corresponding order in Etsy.

Developed for [Priimacraft](https://www.etsy.com/shop/priimacraft/?etsrc=sdt&dd_referrer=https%3A%2F%2Fwww.google.com%2F)
